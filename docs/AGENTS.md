# docs/

Documentation for people.

## Rules
- Write in ASD-STE100 Simplified Technical English. Be short.
- Never type a figure, count, file list or command table by hand. Use a generated block. See `../tools/docs/AGENTS.md`.
- In `video-script.md`, spell out every initialism with a term block or a spoken block, on every use. Add a new initialism to `../tools/docs/glossary.json` first.
- Never name a prospect or a prospect's company.
