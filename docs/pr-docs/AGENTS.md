# docs/pr-docs/

PR planning docs. `README.md` lists them. Done docs move to `archive/`.

## Rules
- Write a PR doc from `template.md` for each PR. See section 0 of the root `AGENTS.md` for the demo-mode exception.
- Name an open PR's doc `<PR number>-<slug>.md`. Name a doc that has no PR yet `planned-<slug>.md`.
- After the merge, set the status to done, move the doc to `archive/` and update `README.md`.
